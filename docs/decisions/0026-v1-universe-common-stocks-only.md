# ADR-0026：v1 證券範圍只有上市、上櫃普通股

狀態：**Accepted**（2026-09-23 owner 決定），隨 schema v2 第一步（ROADMAP Step 35-a）生效。
§3 由 ADR-0028 局部取代（2026-09-25）：清單收 2020 年以後下市、證明為普通股的公司，其資料仍不收。
收窄 ROADMAP §1 與 CLAUDE.md「v1 Scope」的證券範圍；影響 ADR-0023（ETF 分割/反分割結果檔）。

## 背景

v1 原本的範圍是「上市（`sii`）與上櫃（`otc`）」，以市場別定義，沒有限制證券種類。
所以全市場檔裡的每一種商品都被收進來。`stockdc_backfill` 的日行情（2020-01-02 →
2026-09-11）依代號格式粗分：

```text
4 碼個股                2,057 檔   2,944,081 列
ETF／ETN（00 開頭）        411 檔     415,234 列
指數投資證券（020000 等）    48 檔
特別股（2881A 等）           35 檔      42,531 列
TDR（910322 等）              9 檔      10,740 列
受益證券（01001T 等）         7 檔
```

legacy `stock_db` 的 `daily_quotes` 幾乎只有個股：2,060 檔個股、9 檔 ETF。下游
使用者要的是個股。上面的粗分只用來看規模；代號格式不是證券種類的依據。

## 決策

### 1. v1 只收上市、上櫃的普通股

2026-09-23 owner 決定。排除：

| 排除 | 理由 |
|---|---|
| ETF、ETN、指數投資證券 | 不是個股 |
| 特別股 | 與普通股是不同的證券 |
| 臺灣存託憑證（TDR） | 存託憑證，不是股票 |
| 受益證券（REIT、資產基礎證券） | 不是股票 |
| 創新板 | owner 決定不收，雖然 CFI 同為普通股 |
| 權證 | 原本就未收 |
| 興櫃（`rotc`）、公開發行未上市櫃（`pub`） | 原本就排除 |

KY 公司在範圍內：它們是外國公司直接掛牌的股票，不是存託憑證。

### 2. 篩選依據是官方的有價證券類別，不是代號格式

證交所 ISIN 清單（`isin.twse.com.tw/isin/C_public.jsp`，`strMode=2` 上市、`strMode=4`
上櫃）把每檔證券分在類別標題下。2026-09-23 抓取：

```text
               上市     上櫃
股票          1,054      893      ← 收
創新板           31        —
特別股           28        1
TDR              10        —
ETF             240      119
ETN              15        6
受益證券          6        4
權證         35,327   11,024
```

v1 只收類別為「**股票**」的證券。CFI 代碼不足以單獨判斷：創新板的 CFI 也是
`ESVUFR`，與一般普通股相同。

篩選在 adapter 邊界進行，與既有的 `sii`/`otc` 規則相同：範圍外的列不進入正規化，
計入 manifest 的排除計數，而不是 ingest 之後再刪。

### 3. 以今天的清單為準

2026-09-23 owner 決定：範圍就是**今天** ISIN 清單上的「股票」，不追溯歷史類別。
2020 年以後下市的公司不在清單上，因此它們的歷史資料全部不收。

**已知代價：倖存者偏差。** 回測的股票池只剩存活到今天的公司；下市的多半表現差，
回測績效會偏高。這是 owner 接受的取捨，API 與步驟報告必須揭露它。

清單之後的更新只新增或更新 `stocks` 的列，不刪除：已儲存的歷史會引用它們。

### 4. 既有資料

範圍外證券的 v1 資料不複製到 schema v2（ADR-0027），隨各領域的 v1 表一起 drop。
ADR-0023（ETF 分割/反分割結果檔）因範圍收窄而 **Superseded**：它只服務 ETF。

## 影響

- ROADMAP §1、CLAUDE.md「v1 Scope and Deferred Work」改寫證券範圍的定義。
- `docs/data_domain_inventory.md`、`docs/source_field_audit.md` 記錄類別欄位的出處。
- 所有全市場 adapter 加上類別篩選。
- 各領域與 legacy 的對帳，範圍改為交集內的普通股。
